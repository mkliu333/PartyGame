# PartyGame 聚会小游戏合集

PartyGame 是一个在本地浏览器中运行、由主持人控制流程的聚会小游戏合集。正式游玩时推荐在项目目录运行：

```bash
python -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000/PartyGame.html
```

使用 `localhost` 打开会让音频、Emoji 图片和二维码相关资源更稳定。

---

## 适合什么场景？

适合生日聚会、朋友聚会、家庭聚会、公司团建等现场互动游戏。建议由一位主持人控制电脑页面，其他玩家现场抢答、讨论或投票。

---

## 当前游戏

### 1. 猜台词

看影视片段或图片，抢答下一句台词。

玩法：

* 主持人播放题目片段或展示图片。
* 玩家/队伍抢答台词。
* 主持人揭晓答案。
* 主持人手动给答对的人或队伍加分。

---

### 2. 三歌混播猜歌

三首歌同时播放，抢答分别是哪三首歌。

玩法：

* 每题会同时播放三段音乐。
* 玩家/队伍需要尽量猜出三首歌名。
* 主持人揭晓答案后手动计分。
* 当前题库包括周杰伦、陈奕迅、林俊杰、邓紫棋等分类。

---

### 3. 单曲猜歌

每题播放一段音乐，抢答对应歌名。

玩法：

* 每题播放一段音频。
* 玩家/队伍抢答歌名。
* 支持选择“正放”或“倒放”。
* 主持人揭晓答案后手动计分。

注意：倒放功能建议通过 `localhost` 打开页面使用。

---

### 4. Emoji猜猜猜

根据 Emoji 谐音或图像线索，抢答答案。

玩法：

* 每道题显示一组 Emoji。
* 玩家/队伍根据谐音或图像线索抢答。
* 主持人可以显示提示，也可以直接揭晓答案。
* 每题 1 分，由主持人手动计分。
* Emoji 使用本地 Noto SVG 图片，避免不同电脑显示不一致。

---

### 5. 谁是卧底

谁是卧底是一个个人赛游戏。主持人负责设置规则、发词、组织线下讨论和投票淘汰，玩家通过扫码查看自己的身份词。

基本流程：

* 创建/编辑玩家档案，并设置参与或休息。
* 进入“谁是卧底”设置页。
* 选择题库分类、卧底数量、是否加入白板、是否明示阵营。
* 点击“开始本轮”。
* 主持人按玩家顺序展示二维码。
* 玩家依次扫码查看自己的身份词，不要让别人看到手机。
* 主持人确认所有人看完后点击“开始游戏”。
* 玩家线下描述、讨论并投票。
* 主持人点击被淘汰的玩家并确认。
* 系统自动判断胜负，并显示结算页。

注意事项：

* 谁是卧底只使用个人玩家，不使用团队赛。
* 谁是卧底不使用原来的加减分计分板。
* 二维码用于玩家手机查看自己的词，不要让别人看到手机。
* 游戏结束后会自动显示平民词、卧底词、获胜阵营和获胜玩家。

## 比赛模式

PartyGame 支持两种模式：

### 单人赛

每位玩家独立计分。

### 团体赛

每个队伍作为一个单位计分。

玩家或队伍可以设置头像、改名，也可以切换“参与 / 休息”。休息中的玩家或队伍会保留在列表中，但不会参与当前游戏。

注意：谁是卧底固定为个人赛，会直接进入玩家档案流程。

---

## 计分规则

* 猜台词、三歌混播猜歌、单曲猜歌、Emoji猜猜猜由主持人手动计分。
* 每题揭晓答案后，主持人可以给答对的玩家或队伍加分。
* 如果无人答对，可以选择“此轮没有组别加分”。
* 当前轮结束后会显示本轮结果。
* 游戏结束后可以进行最终结算。
* 谁是卧底不进入这个计分流程，使用自己的投票淘汰和胜负结算。

## 顶部功能

### 主题切换

页面顶部可以切换不同 UI 主题。当前主题包括：

* 经典奶油
* 草莓波普
* 薄荷气泡
* 星空霓虹
* 复古街机

主题只保存在当前页面内存中，刷新页面后会恢复默认主题。

### 重置所有游戏

“重置所有游戏”会重置所有游戏的题库 / 音频库存，让已经抽过的题目重新可用。

注意：

* 不会删除玩家或队伍。
* 不会清空已创建的身份。
* 游戏进行中会隐藏该按钮，避免误操作。

### 回到首页

游戏进行中点击“回到首页”会弹出确认。如果确认退出，当前未完成轮次会回滚，不会把未完成题目算作已消耗。

## 运行方式

### 方式一：直接打开

双击打开：

```text
PartyGame.html
```

适合简单浏览和基础游玩。

### 方式二：推荐正式游玩方式

在项目根目录打开终端，运行：

```bash
python -m http.server 8000
```

然后浏览器打开：

```text
http://localhost:8000/PartyGame.html
```

如果页面没有更新，可以按：

```text
Ctrl + F5
```

进行强制刷新。

---

## 注意事项

* 本项目是本地静态网页，不需要后端。
* 不使用数据库。
* 不使用 `localStorage` 或 `sessionStorage`。
* 刷新或关闭页面后，当前玩家、分数和游戏进度会自然重置。
* 正式游玩前建议确认音频、视频、图片、Emoji 和二维码都能正常加载。
* 如果 Emoji 显示异常、音频倒放不可用或二维码资源异常，请使用 `localhost` 方式打开。
* 建议由主持人统一操作电脑，现场玩家口头抢答、讨论或投票。

## 给主持人的快速检查清单

正式开始前建议检查：

1. 是否能正常打开首页。
2. 是否已经创建好玩家或队伍。
3. 猜台词素材是否能播放。

5. 单曲猜歌正放 / 倒放是否能播放。
6. Emoji猜猜猜是否能显示 Emoji 图片。
7. 谁是卧底二维码是否能正常显示。
8. 计分按钮、投票确认和结算页面是否正常。

推荐正式游玩地址：

```text
http://localhost:8000/PartyGame.html
```
